# Poor Health & Food

### Overview  
Using Python, this project focused on statistical analysis of PLACES, a CDC health dataset with health outcomes and potential risk factors. Data was cleaned before conducting linear and logistic regression to identify the strongest predictors of poor health status. Data was visualized through the workflow (Jupyter Notebook).

Dataset: [CDC PLACES](https://www.cdc.gov/places/index.html)

---

### Workflow
- Data loading and cleaning
- Data exploration
- Data modeling
